# 园图 parkmap MCP 连接器

让你的 AI Agent（Kimi、Claude、Cursor 等支持 MCP 的客户端）直接查询园图 parkmap 平台的园区、政策、租金与选址评估数据。

## 它能带来什么能力

接入后，你的 Agent 可以使用 7 个只读工具：

| 工具 | 说明 | 所需档位 |
| --- | --- | --- |
| `search_parks` | 按城市/区县/产业方向/租金区间/关键词检索园区 | 免费档 |
| `get_park` | 单个园区档案（高档位自动附带政策/活动/租户/评估/选址要素） | 免费档 |
| `list_news` | 园区资讯：立项/活动/新政/考察/动态 | 免费档 |
| `list_policies` | 扶持政策检索，结果带园区归属 | 个人 API 会员 |
| `get_policy` | 政策全文详情 | 个人 API 会员 |
| `get_region_stats` | 区域统计：各区园区数、平均租金、产业分布 | 个人 API 会员 |
| `get_evaluations` | 十维选址评估档案（人工建档评分） | 企业 API 会员 |

所有工具只读，不写入任何数据。每次调用返回数据的同时附带当日/当月剩余配额，Agent 可自动控制调用节奏。

## 数据档位与配额

> ⚠️ 2026-10-17 起，MCP 数据服务为**正式会员权益**：试用期与未办理会员的账号
> 无法生成/使用 API Key。办理任意正式会员卡（月/季/年）后，免费档工具即可用；
> 政策/统计/评估类工具需再兑换对应 API 会员卡提档。

| 档位 | 配额 | 数据范围 | 获取方式 |
| --- | --- | --- | --- |
| 免费档 | 100 次/日 · 1,000 次/月 | 园区基础数据、园区资讯 | 正式会员即享 |
| 个人 API 会员 | 500 次/日 · 20,000 次/月 | ＋政策全文、区域统计 | 个人 API 会员卡 |
| 企业 API 会员 | 5,000 次/日 · 200,000 次/月 | ＋十维评估、入驻企业公开名单、选址要素 siteFactors | 企业 API 会员卡 |

### 选址要素 siteFactors（企业 API 会员）

`get_park` 在企业档下额外返回 `siteFactors` 扩展块，覆盖企业选址的成本与硬件核心参数，供 Agent 做选址测算与多园区横评：

| 子块 | 字段 | 单位 / 说明 |
| --- | --- | --- |
| `costs` | `propertyFee` | 物业费，元/㎡/月 |
| `costs` | `electricity` / `water` / `gas` / `steam` | 能耗单价，元/kWh、元/吨、元/m³、元/吨 |
| `costs` | `freeRentMonths` | 免租期，月 |
| `specs` | `floorHeight` / `floorLoad` / `columnSpacing` | 层高 m / 承重 kg/㎡ / 柱距 m |
| `specs` | `elevatorTonnage` / `powerCapacity` / `dualCircuit` | 货梯吨位 t / 供电容量 kVA / 双回路供电 |
| `specs` | `fireRating` | 消防等级 |
| `platforms` | `[{name, type}]` | 公共平台名录（检测/中试/实验/孵化等） |
| — | `confidence` | 数据分级：L1 官方溯源 / L2 参考 / L3 运营估算 |
| — | `note` | 来源与口径说明（L3 估算必有） |

字段按需逐步建档，未建档园区不返回该块；`confidence` 为 L3 的数据为估算值，Agent 回答用户时必须如实转述估算属性。

兑换对应 API 会员卡即时提档，无需更换 Key。超限返回 429，次日/次月自动恢复；企业客户可联系平台定制更高配额。

## 安装步骤

1. 解压本包到任意目录，例如 `~/parkmap-mcp`
2. 安装依赖（Python 3.10+，仅标准库，无第三方依赖）：

   ```bash
   pip install -r requirements.txt
   ```

3. 到园图 parkmap「账号管理 → 工作台」生成你的 API Key（以 `pmk_` 开头，仅显示一次，请妥善保存；需正式会员身份）

4. 在你的 MCP 客户端配置中注册（以 Claude Desktop / Kimi 为例）：

   ```json
   {
     "mcpServers": {
       "parkmap": {
         "command": "python",
         "args": ["~/parkmap-mcp/server.py"],
         "env": {
           "PARKMAP_API_KEY": "pmk_你的key",
           "PARKMAP_API_BASE": "https://parkmap.cn"
         }
       }
     }
   }
   ```

5. 重启客户端，对 Agent 说「帮我找海淀区 8 元/㎡/天以内的人工智能园区」即可验证。

## 使用中的引导与提醒（v0.4.0 新增）

连接器把「需要用户行动」的情况做成**会话内消息提醒**，Agent 会原样转述并附官网链接：

| 情况 | 你会看到 | 该怎么做 |
| --- | --- | --- |
| 未配置 Key | ⚠️ 引导消息 + 自动弹出官网注册页（每次启动客户端最多弹一次） | 注册/登录 → 办会员 → 生成 Key → 写入配置重启 |
| Key 无效/被吊销（401） | ⚠️ 提醒 + 工作台链接 | 重新生成 Key 并更新配置 |
| 试用期/未办会员（403） | ⚠️ 提醒 + 会员卡商城链接 | 办理正式会员后即用 |
| 会员已过期（403） | ⚠️ 提醒 + 续费链接 | 续费后立即恢复，无需换 Key |
| 档位不足（403） | ⚠️ 提醒 + 升级链接 | 兑换对应 API 会员卡，即时提档 |
| 配额耗尽（429） | ⚠️ 今日/本月用量 + 升级链接 | 次日/次月自动恢复，或升级会员 |

弹窗依赖操作系统默认浏览器；服务器等无桌面环境弹不出时，消息里的链接同样可达。

## 常见问题

- **401 Key 无效**：确认 Key 未吊销、配置的环境变量名是 `PARKMAP_API_KEY`；Key 泄露请立即到平台吊销并重新生成。
- **403 档位不足**：该工具需要个人/企业 API 会员，兑换对应 API 会员卡后即时生效，无需换 Key。
- **429 配额耗尽**：次日/次月自动恢复；高频场景请联系平台定制配额。
- **连接失败**：检查 `PARKMAP_API_BASE` 是否可达；企业内网需放行 443 端口。

## 安全说明

- 平台只存 Key 的 SHA-256 哈希，完整 Key 仅生成时显示一次。
- 每次调用在服务端留痕（端点、状态码、时间），用于配额管理与安全审计。
- 接口输出不包含租户联系方式等非公开字段；评估档案等深度数据仅企业档可见。

## 环境变量

| 变量 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `PARKMAP_API_KEY` | 是 | — | API Key（`pmk_` 开头） |
| `PARKMAP_API_BASE` | 否 | `https://parkmap.cn` | 数据接口地址（v0.4.0 及更早默认为 `https://api.parkmap.cn`，该域名未启用，请升级或显式改为 `https://parkmap.cn`） |
| `PARKMAP_SITE_BASE` | 否 | `https://parkmap.cn` | 官网地址（引导消息中的链接前缀） |
| `PARKMAP_NO_BROWSER` | 否 | — | 设为 `1` 禁用缺 Key 时的自动弹窗（无桌面环境适用） |
